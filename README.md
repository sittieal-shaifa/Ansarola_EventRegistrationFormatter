# Student Event Registration Formatter

## Description
This program formats student event registration details. It collects the student's first name, last name, section, event name, and event date, then displays the information in a clean and organized format.

## Language Used
- Python

## String Feature Used
- `strip()` - Removes unnecessary spaces at the beginning and end of text.
- `title()` - Capitalizes the first letter of each word.
- `upper()` - Converts all letters into uppercase.

## Date/Time Feature Used
- `datetime` - Creates and formats the event date into a readable format.

## Version History
- **Version 1:** Basic input and output.
- **Version 2:** Added string formatting.
- **Version 3:** Added date formatting using datetime.

## Reflection
In my first version, my program could collect and display basic student and event information.

I improved my program by adding string formatting and date formatting.

The string methods I used were strip(), title(), and upper() because they help clean and organize the text.

The date/time feature I used was datetime because it allows me to display the event date in a readable format.

The biggest change in my program was making the registration information cleaner, more organized, and easier to read.
